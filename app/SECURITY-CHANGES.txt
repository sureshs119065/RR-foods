SECURITY AND SEO UPDATE (Nov 2026)

CHANGED
- requirements.txt: Pillow >=13.0,<14 (12.x had 15+ published advisories; it handles every image upload). Run: pip install -U -r requirements.txt
- app/services/checkout.py: a bundle price saved in the cart is re-checked at checkout. If the bundle is switched off, expired, not started, or edited after the customer added it, checkout stops with a clear message.
- app/uploads.py: videos are checked by their real first bytes (MP4/MOV 'ftyp', WebM header), not just the file extension and browser-sent type.
- app/__init__.py: adds Cross-Origin-Opener-Policy, and Strict-Transport-Security when the request arrives over HTTPS (needs TRUST_PROXY=1 behind nginx).
- app/shop/catalog.py: /favicon.ico route; sitemap now has <lastmod> for products and lists About, Bundles and Recipes.
- app/templates/base.html, shop/product.html, shop/home.html: default Open Graph and Twitter tags on every page (product pages keep their own), Organization and WebSite JSON-LD on the home page.
- deploy/nginx.conf: limit_req_status 429, gzip_vary and more gzip types.

ADDED
- deploy/nginx-https.conf: final HTTPS config (redirect, HTTP/2, HSTS, no version in Server header).
- tests/test_security_part2.py: 45 tests (coupons, stock race, cart tampering, bundle price, order/address IDOR, role separation, login lockout, headers, video upload, SEO).
- tools/part3_site_checks.sh: live-site checks. Usage: bash tools/part3_site_checks.sh https://your-site
- tools/k6_shop_load.js: load test. Usage: k6 run -e BASE=https://staging-site tools/k6_shop_load.js
